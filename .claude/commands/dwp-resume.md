# /dwp-resume

Read [`docs/DEEP_WORK_PLANS.md`](../../docs/DEEP_WORK_PLANS.md) and follow the
**resume** flow.

- Re-read the plan and its recorded evidence before doing anything: the tree may
  have changed since the last session.
- Re-run the last completed task's gate if anything looks inconsistent — trust
  the gate, not the checkbox.
- Then continue with the first unfinished task.
