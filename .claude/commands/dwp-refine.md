# /dwp-refine

Read [`docs/DEEP_WORK_PLANS.md`](../../docs/DEEP_WORK_PLANS.md) and follow the
**refine** flow.

- Task ids are stable: never renumber an existing one. New work gets a new id.
- Say what changed and why, in the plan itself.
- `promote` converts a Lite plan to Full (one file per task) when a compact
  record can no longer carry its requirements or its gate.
