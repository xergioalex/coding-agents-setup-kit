# /dwp-execute

Read [`docs/DEEP_WORK_PLANS.md`](../../docs/DEEP_WORK_PLANS.md) and follow the
**execute** flow.

- One task at a time, in order. Stay inside that task's touched surface.
- Run the task's validation gate and record its **real output** as completion
  evidence. Never mark a task done without it.
- Stop and ask when a task needs a decision the human owns (their `$HOME`, their
  SSH config, their Herdr catalog, publishing or pushing).
- Finish with the **Final Review**: security pass against `docs/SECURITY.md`, the
  full `tests/run.sh` on the final tree, and documentation reconciliation.
